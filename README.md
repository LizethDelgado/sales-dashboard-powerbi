# Sales Performance Dashboard (Power BI)

## Overview
This project presents a Power BI dashboard focused on sales performance analysis.

## Objectives
- Analyze revenue trends over time
- Evaluate profitability and profit margin
- Identify top-performing categories and regions
- Compare year-over-year growth

## Tools
- Power BI
- DAX
- Sample Superstore Dataset

## Key Features
- KPIs: Sales, Profit, Orders, Profit Margin
- Year-over-Year analysis
- Sales by Category and Region
- Scatter plot (Sales vs Profit)

## Insights
- Sales show consistent growth over time
- Technology is the top-performing category
- The West region has the highest sales
